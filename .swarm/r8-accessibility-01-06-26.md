## Summary (Top 5 Fixes by Impact + Ease)

1. **Error Message Announcements** (Medium impact, easy fix): Add `role="alert" aria-live="assertive"` to creator/tag/publish error divs in ShareModal. Currently, users on screen readers may miss validation failures entirely. Fixes 3-4 instances across the modal (estimated 15 min).

2. **Comment & Form Input Labels** (Medium impact, easy fix): Add visible or ARIA labels to comment form inputs in CommentSection. Currently inputs rely on context alone. Add `<label htmlFor>` pairs or `aria-labelledby` (estimated 20 min).

3. **Feedback Type Selector Color Dependence** (High impact, medium ease): Add visible text labels to feedback type buttons (Feature/Bug/Improvement/Other). Color alone fails WCAG 1.4.1. Inline 12px text labels below icons solves this (estimated 10 min).

4. **Dropdown ARIA Completeness** (Low impact, easy fix): Add `aria-owns` to menu button and `aria-controls` to listbox buttons. Improves AT navigation without breaking current UX (estimated 15 min).

5. **Theme Selector Visibility** (Medium impact, medium ease): Add visible text labels to theme selector buttons so users understand which theme is selected. Currently icons are decorative and state is invisible to low-vision users (estimated 20 min).

**Overall Risk:** Low. No critical blocking issues; all findings are refinements to existing patterns that already have basic keyboard support and focus management.
