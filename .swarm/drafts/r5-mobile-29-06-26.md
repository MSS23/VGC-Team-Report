### 2c. Kick off render on modal open (new useEffect near the existing ones, ~line 100)

```ts
// Pre-render the team card PNG once the modal opens so the native share
// sheet doesn't pay a 1–2s html2canvas cost when the user taps "Share via…".
// We render lazily after first paint to avoid blocking the modal animation.
useEffect(() => {
  if (teamSpecies.length === 0) return;
  let cancelled = false;
  const timer = setTimeout(async () => {
    try {
      if (!captureRef.current) return;
      const html2canvas = await getHtml2Canvas();
      const canvas = await html2canvas(captureRef.current, {
        useCORS: true,
        scale: 2,
        backgroundColor: null,
      });
      if (cancelled) return;
      const blob: Blob | null = await new Promise((res) =>
        canvas.toBlob(res, "image/png"),
      );
      if (!cancelled && blob) {
        teamCardBlobRef.current = blob;
      }
    } catch {
      // Sprite CORS / canvas tainting / OOM — silently fall back to URL-only share.
    }
  }, 300);
  return () => {
    cancelled = true;
    clearTimeout(timer);
  };
}, [teamSpecies]);
```

### 2d. Updated `handleNativeShare` (replace lines 291–301)

```ts
const handleNativeShare = async () => {
  const title = tournamentName
    ? `${tournamentName}${placement ? ` (${placement})` : ""} VGC Team Report`
    : "VGC Team Report";

  let withImage = false;
  let sharePayload: ShareData = { title, url: publicUrl };

  // Try to include the team-card PNG. canShare() guard handles browsers
  // where Web Share L2 (files) is missing — they fall back to URL-only.
  try {
    const blob = teamCardBlobRef.current;
    if (blob && typeof navigator.canShare === "function") {
      const fileName = `${(teamName || tournamentName || "vgc-team")
        .toLowerCase()
        .replace(/\s+/g, "-")}.png`;
      const file = new File([blob], fileName, { type: "image/png" });
      const candidate: ShareData = { title, url: publicUrl, files: [file] };
      if (navigator.canShare(candidate)) {
        sharePayload = candidate;
        withImage = true;
      }
    }
  } catch {
    // Fall through to URL-only share.
  }

  try {
    await navigator.share(sharePayload);
    posthog?.capture("share_native_used", {
      has_tournament: !!tournamentName,
      with_image: withImage,
    });
  } catch {
    // User cancelled or share failed — no-op.
  }
};
```

## 3. Test matrix

Manual smoke test before pushing — copy this checklist into a Linear comment when shipping.

| Surface | Receives image? | Expected behaviour |
|---|---|---|
| iOS Safari → iMessage | Yes | Image attaches inline above the URL preview |
| iOS Safari → WhatsApp | Yes | Image-with-caption (URL in caption) |
| iOS Safari → Instagram Stories | Yes | Stories composer opens with PNG pre-loaded |
| iOS Safari → Twitter/X | No (URL only) | Tweet composer opens with URL (no regression) |
| iOS Chrome | Falls back to URL-only | Chrome iOS doesn't expose Web Share files |
| Android Chrome → WhatsApp | Yes | Image attaches |
| Android Chrome → Discord | Yes | PNG attaches to message |
| Android Firefox | Falls back to URL-only | canShare({files}) returns false |
| Desktop Chrome | URL-only (no native share button visible on desktop modal) | Unchanged |
| User cancels share sheet | No-op | No error toast, no analytics event |
| Sprite CORS error during render | URL-only | Blob never populates, share proceeds without files |
