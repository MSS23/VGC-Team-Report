# R8 — WCAG 2.1 AA Static Audit (marketing + report viewer)

Scope: `src/app/page.tsx`, `src/app/layout.tsx`, `src/app/explore/page.tsx`, `src/app/champions/page.tsx`, `src/app/s/[id]/*`, key components (`PageNavbar`, `Navbar`, `ShareModal`, `Toggle`, `Button`, `ReportCard`, `WalkthroughOverlay`).

## Top 10 issues (severity ordered)

1. **P0 — 2.5.5 Target size.** `src/components/layout/PageNavbar.tsx:43-65` — desktop nav links are `px-3 py-1.5 text-xs` (~28px tall). Below 44×44 AA recommendation; fail Apple/MS guidance. Fix: bump to `py-2.5 min-h-[40px]` or wrap in 44px tap area.
2. **P0 — 2.5.5 Target size.** `PageNavbar.tsx:82` — `UserButton` forced to `w-7 h-7` (28×28). Fix: drop the appearance override or wrap with a 44px hit zone.
3. **P0 — 1.3.1 Info & relationships / 4.1.2 Name.** `src/app/s/[id]/redirect.tsx:14-24` — auto-redirect runs without `aria-live` announcement; visually hidden H1 only; screen reader users get no progress feedback. Fix: add `role="status" aria-live="polite"` to the spinner block and add `<meta http-equiv="refresh">` fallback.
4. **P1 — 1.4.3 Contrast (small text).** `text-[9px]` + `text-text-tertiary` (`#5E5E7A` on `#FFFFFF` ≈ 5.3:1; `#9898B8` on `#0B0B1A` ≈ 6.1:1) — ratio passes, but at 9px the fonts visually fail readability (WCAG 1.4.4 reflow / cognitive). Hits `LanguageSelector.tsx:81`, `ShareModal.tsx:754/777/805`, `OTSSheetModal.tsx:237`, `page.tsx:1098/1708`. Fix: minimum text-[11px] for body labels.
5. **P1 — 2.4.7 Focus visible.** `src/components/layout/PageNavbar.tsx` Link elements and `src/components/ui/Toggle.tsx:10` `button` rely on UA default outline; no `focus-visible:ring-*` declared on Links. Fix: add `focus-visible:ring-2 focus-visible:ring-accent` to all nav links + Toggle.
6. **P1 — 4.1.2 Name/role/value.** `Toggle.tsx:10-24` — switch button has no visible label association; `aria-label` is set but the adjacent text `<span>` is `hidden sm:inline`, so on mobile sighted users have only an icon-less pill. Fix: render the label visibly on mobile or include it as text inside the button.
7. **P1 — 1.4.11 Non-text contrast.** `Toggle.tsx:15` off-state uses `bg-border` (`#E0DDD5` on `#FFFFFF` ≈ 1.3:1). Track must be ≥3:1 vs surface for UI components. Fix: use `bg-text-tertiary` or `bg-border-strong`.
8. **P1 — 2.1.1 Keyboard / 2.4.3 Focus order.** `src/app/page.tsx:296-300` ShareModal portal uses backdrop `onClick` close but the wrapper has no `role="presentation"` and the focusable backdrop is reachable via Tab in some browsers. Fix: add `aria-hidden` on backdrop, ensure body inert.
9. **P2 — 1.1.1 Non-text content.** `ReportCard.tsx:52-60` — `<img alt={species}>` is fine, but the surrounding `motion.a` lacks an accessible name describing the whole card (placement, tournament, creator). Fix: add `aria-label` to the link summarizing the card.
10. **P2 — 1.3.1 Heading hierarchy.** `ExploreHero.tsx:10` uses `<h1>` while layout's `PersistentNavbar` outputs a logo `<Link>` (fine), but `page.tsx:785` uses `<h2>` for collab gate with no preceding `<h1>` on that branch. Fix: promote to `<h1>` when shown standalone.
