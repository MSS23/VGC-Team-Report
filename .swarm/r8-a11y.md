### 2. Non-Button Clickable Divs/Spans (HIGH)

**WCAG Criterion:** 2.1.1 Keyboard (Level A) | 4.1.2 Name, Role, Value (Level A)

#### Issue A: ShareModal URL Display
- **FILE:** `/home/user/VGC-Team-Report/src/components/ui/ShareModal.tsx:395-409`
- **ISSUE:** `<div role="button" tabIndex={0}` used instead of `<button>` for copy link action
- **SNIPPET:**
  ```tsx
  <div
    className="flex items-center gap-2 bg-surface-alt border border-border rounded-xl px-4 py-2.5 cursor-pointer hover:border-accent/40 transition-colors"
    onClick={handleCopyLink}
    role="button"
    tabIndex={0}
    aria-label="Copy link"
    onKeyDown={(e) => { if (e.key === "Enter" || e.key === " ") { e.preventDefault(); handleCopyLink(); } }}
  ```

- **PRIORITY:** Medium
- **IMPACT:** While functional for keyboard users (due to explicit onKeyDown), a native button is semantically correct and requires less custom code.
