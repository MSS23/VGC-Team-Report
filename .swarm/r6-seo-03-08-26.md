# R6 — SEO Posture Audit vs Competitors, 3 August 2026

**Agent:** R6 (overnight research swarm) · **Mode:** READ-ONLY, recommendations only · **Nothing published, posted, or committed.**

Scope: (1) full inventory of in-repo SEO assets, (2) competitor SERP study for VGC team-building / team-sharing queries, (3) top-10 keyword gaps, (4) capture route + effort per gap. Findings that duplicate VGC-217 / VGC-227 / VGC-148 / VGC-184 / VGC-64 are marked **ALREADY-TICKETED** and excluded from the top recommendations.

**Headline:** the site's entire public SEO surface is pinned to **Regulation M-A**, which stopped being the live format on **17 June 2026**. Reg M-B is the current format and the **2026 Worlds format**. The data layer already fully supports M-B (`CHAMPIONS_MB_DEX`, `CHAMPIONS_REG_MB_MEGAS`, `getRegMBMegas()`, `detect-regulation.ts`) — but `generateStaticParams`, the sitemap, and every metadata string still say M-A. **14 sprited Reg M-B Megas — including Mega Metagross, Mega Blaziken, Mega Swampert, Mega Mawile — have no landing page at all**, while Pikalytics, Pokemon-Zone and MetaVGC each rank a page for every one of them.

### 1.2 robots — `public/robots.txt` (static file; **no `robots.ts`**)

```
User-agent: *
Allow: /
Disallow: /api/

User-agent: Googlebot
Allow: /
...
Sitemap: https://pokemonvgcteamreport.com/sitemap.xml
```

**Defect (real, not cosmetic).** Per RFC 9309, a crawler obeys **only the most specific matching group** — the wildcard group is then ignored entirely. Because `Googlebot`, `Bingbot`, `GPTBot`, `ClaudeBot`, `PerplexityBot` and `OAI-SearchBot` each get their own group containing *only* `Allow: /`, **`Disallow: /api/` does not apply to any of them.** The named groups were added to be welcoming and accidentally un-blocked the API surface for every crawler that matters. Every named group needs its own `Disallow: /api/` line (or the named groups should be deleted — the wildcard group already allows everything).

Also missing: `Disallow: /embed/`, and no crawl guidance for `?key=` collab URLs (those are handled correctly at the meta level, see 1.4).

### 1.6 AI-discoverability files — `public/llms.txt`, `public/llms-full.txt`

Well-structured per llmstxt.org. **But `llms.txt` is factually wrong on the single mechanic this site is differentiated by:**

> "**SP (Standard Points) vs EVs:** SP is an alternative stat-expression system used in some reporting contexts. **1 SP = 1 EV** (effort value)."

Both halves are false. SP is **Stat Points**, a real in-game Champions system: **66 total, max 32 per stat**, converted via the HOME rule (first SP costs 4 EVs, each additional SP costs 8). This is exactly what `convertToChampionsSp` in `src/lib/analysis/stat-calculator.ts` implements. The file is also stamped `Updated: 2026-05-23` and **never mentions Reg M-B**. Since llms.txt exists specifically to be ingested by ChatGPT/Claude/Perplexity, this is an active mis-citation liability — we are feeding assistants a wrong answer about our own core feature while ChampDex and RotomLabs feed them the right one.

- `PageNavbar.tsx` `NAV_LINKS`: Home, Explore, Champions, Compare, Updates, Feedback. **Missing `/tournaments` and `/faq`.**
- Mega guides cross-link 8 related Megas each (`page.tsx:186`) — good hub-and-spoke, but the related set is drawn from `getRegMAMegasWithSprites()`, so it will not link to M-B pages once they exist.

### 1.8 Other technical findings

- **Homepage H1 is brand-only.** `PasteInput.tsx:275` renders `{t.appTitle}{t.appTitleAccent}` = **"VGC Team Report"**. The `<title>` targets "Build and Share Pokemon VGC Teams" but the H1 on our highest-authority page carries no keyword. Cheapest on-page win in the repo.
- **`vgc-team-report.vercel.app` is independently indexed.** It surfaces in Google as its own result with a *stale description* ("transform your Pokemon Showdown VGC paste into a clean, professional team report") that no longer matches prod. `src/proxy.ts:63` computes `isPreviewDeploy = host.includes('vercel.app') && host !== 'vgc-team-report.vercel.app'`, which *should* 301 that host to the canonical domain — so this is either a stale index entry needing a Search Console removal, or the redirect isn't firing for crawlers. Either way it is live duplicate-content dilution. (Adjacent to **VGC-64**, but the domain-dedup task itself is not the sitemap/GSC-setup task.)
- **`/embed/[id]` cannot actually be embedded.** `next.config.ts:80` sets `X-Frame-Options: DENY` and line 147 sets `frame-ancestors 'none'` on `source: "/(.*)"` — with no exception for `/embed/`. The ShareModal's "Copy Embed" button hands users an iframe snippet that will be blocked in every browser. Embeds are a first-order backlink and referral channel (this is how tools like PokePaste and Pikalytics propagate across blogs and Discord-linked sites), so this is a distribution bug with direct SEO consequence. Adjacent to **VGC-148/VGC-184** but distinct: those are outreach, this is a broken mechanism.
- **`/api/champions/meta`** computes a top-20 usage snapshot from public Champions reports, cached 5 min — and is rendered nowhere indexable. Free content for a usage page (gap #9).
- Sitemap will exceed 10k URLs as shares grow; the 50k/50MB limit is far off, so no action needed yet, but worth a note for VGC-64.

## 2. Competitor SERP study — what actually ranks

Studied via live search: pikalytics.com, vgcpastes (X/Discord + repository), pokepast.es, victoryroad.pro, limitlesstcg, plus the 2026 entrants the older audits didn't have: teamsheet.gg, champdex.com, rotomlabs.net, pokesynergy.app, metavgc.com, pokemon-zone.com, vgclite.com, pokestats.cc, champsdex.com, vgenc.net.

### Page types that rank

| Competitor | Winning page type | URL shape |
|---|---|---|
| **Pikalytics** | Per-species-per-format stat pages (the dominant pattern) | `/pokedex/{format}/{Species}` e.g. `/pokedex/gen9championsvgc2026regma/Metagross-Mega`, `/pokedex/battledataregmbs3/metagross` |
| Pikalytics | Format hub | `/pokedex/gen9championsvgc2026regma`, `/` (reframed per active reg) |
| Pikalytics | Standalone tool pages | `/speed-tiers`, `/calc`, `/team`, `/topteams` |
| Pikalytics | **Event hub** | `/worlds-2026` |
| **Victory Road** | Authoritative rules/format pages | `/champions-regulations/`, `/sv-rules-regulations/`, `/2026-worlds/`, `/2026-season-calendar/` |
| Victory Road | Replica-team hub | `/champions-replica/` |
| **Pokemon-Zone** | Per-species moveset/strategy | `/champions/pokemon/{base}-mega-{name}/` |
| **ChampDex** | Mechanic explainers + micro-tools | `/guides/stat-points`, `/guides/format-rules`, `/tools/ev-converter` |
| **RotomLabs / ChampCalc** | Single-purpose converters | `/champions/stat-converter` |
| **PokeStats / PikaChampions / PokeSynergy** | Guide-shaped listicles | `/guides/vgc-speed-tiers`, `/guides/vgc-format-guide` |
| **teamsheet.gg** | **Direct competitor to our core product** — "turn a pokepaste into a beautiful team report" | `/`, `/generator` |
| **VGCPastes** | Curated paste repository (spreadsheet + X) — ranks on topical authority, not page structure | — |
| **PokePaste** | Raw paste hosting; ranks for its own entity only | `/{hash}` |
| **Limitless** | Tournament results/standings | `/tournament/{id}/details` |

### Three structural reads

1. **Per-entity × per-format pages are the entire game.** Pikalytics ships one page per species per regulation and owns the long tail by volume. Our `/champions/[pokemon]` template is the *correct shape* — it's just wired to 58 M-A entries and nothing else.
2. **Single-purpose tool pages at their own URL beat tools buried inside an app.** ChampDex, RotomLabs, ChampCalc, teamsheet.gg all rank with pages that do exactly one thing. We own five such tools (SP converter, speed tiers, OTS sheet, team graphic, compare) and expose exactly one of them (`/compare`) at a URL — and `/compare` is set to `noindex`.
3. **A new direct competitor exists that the previous audits didn't see.** `teamsheet.gg` markets itself as "Pokemon Team Reports" and "turn a pokepaste into a beautiful team report" — the exact positioning of this product. The "VGC team report" keyword is no longer uncontested.

### Gap 1 — Reg M-B Mega species queries · **NOT TICKETED** · ~1h

**Queries:** `mega metagross vgc`, `mega metagross champions best moveset`, `mega blaziken champions`, `mega swampert vgc 2026`, `mega mawile reg m-b`, `mega sceptile champions`, `mega staraptor contrary`, `reg m-b megas list`, and 14× the `{Mega} SP spread` / `{Mega} moveset` / `{Mega} teams` cluster the existing template already targets.

**Why it's a gap:** we have zero pages. Pikalytics ranks `/pokedex/battledataregmbs3/{mon}` and `/pokedex/championstournaments/{Mon}`; Pokemon-Zone ranks `/champions/pokemon/metagross-mega-metagross/`; MetaVGC ranks `/pokemon/metagross-mega`. Mega Metagross alone shows 4,800+ recorded tournament games in Pikalytics' Reg M-B dataset — it is a top-meta Pokémon with an active search curve, and Worlds is 25 days out.

**Capture route:** the pages already exist as a template. Add `getRegMBMegasWithSprites()` beside `getRegMAMegasWithSprites()` in `src/lib/data/mega-pokemon.ts` (three-line function; `MEGAS_WITH_SPRITES` already lists all 14 M-B slugs, probed June 2026), then swap the three call sites — `champions/[pokemon]/page.tsx:23` (`generateStaticParams`), `:186` (`relatedMegas`), `sitemap.ts:24` — plus `champions/page.tsx:38` and `ChampionsContent.tsx:16` for the index grid.

**Effort:** ~1 hour. This is the single highest ratio in the audit: 14 new indexable pages, a template that is already shipped and proven, and data that is already in the repo.

### Gap 2 — "M-A vs M-B" format-currency queries · **NOT TICKETED** · ~1h (bundled with Gap 1)

**Queries:** `pokemon champions reg m-b`, `regulation m-b legal pokemon`, `what's new in reg m-b`, `m-a vs m-b differences`, `reg m-b worlds format`.

**Why it's a gap:** every metadata string, `<h1>`, and FAQ answer we publish says "Regulation M-A" — the format that ended 17 June. `generateMetadata` at `champions/[pokemon]/page.tsx:38–39` hardcodes *"Pokemon Champions Regulation M-A"* into the title and description of all 58 pages, and the FAQ JSON-LD at `:218` asserts *"Is {Mega} legal in VGC 2026 Regulation M-A? Yes"*. For a Mega that is M-A-legal that's still true, but the page reads as stale to both users and crawlers during the M-B/Worlds window.

**Capture route:** parameterise the M-A/M-B string off `CHAMPIONS_REG_MB_ONLY_MEGAS.has(dataKey)` in `generateMetadata` and in the FAQ builder; add a "Reg M-B" line to `/champions` copy and to `llms.txt`. Ship with Gap 1 as one change.

**Effort:** ~1 hour, same PR as Gap 1.

### Gap 4 — Replica / rental team-code queries · **NOT TICKETED** · ~3h

**Queries:** `pokemon champions replica teams`, `pokemon champions team codes`, `champions rental codes 2026`, `pokemon champions team id codes`, `best replica teams champions`.

**Why it's a gap:** high-intent, high-refresh, and dominated by low-quality aggregators — Pro Game Guides, Game8, ChampsDex, ffbooyah — alongside Victory Road's `/champions-replica/`. **We already store the data**: `rentalCode` is a first-class field (`url-codec.ts:75`, `normalize-report.ts:111`) with a working DB-side filter (`api/explore/route.ts:142–145`, `hasRental`) and a "Rental" badge on cards. We are sitting on a continuously-refreshed, community-supplied corpus of codes attached to *explained* teams and exposing it only behind a filter pill.

**Terminology note:** the official in-game feature is **"Replica Teams"** (10-character Team IDs, Training → Replica Teams), not "rental teams" — that's a Scarlet/Violet term. Our UI says "Rental code" throughout. The page should target *both*, headline "Replica".

**Capture route:** new SSG-with-ISR route `/champions/replica-teams` rendering `ExploreContent` pre-filtered to `hasRental=true`, plus an explainer section on how to redeem a Team ID, `ItemList` + `FAQPage` + `BreadcrumbList` schema. Zero manual upkeep — the list refreshes as creators publish.

**Effort:** ~3h. Best data-already-exists ratio after Gap 1.
