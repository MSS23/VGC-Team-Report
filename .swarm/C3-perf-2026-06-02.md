## Top 5 Highest-Leverage Wins

### 1. Motion library on critical path (Homepage & Explore) — ~90 KB reduction
**Severity:** HIGH | **Risk:** LOW | **Conflict Risk:** NO

**File:** `/src/components/input/PasteInput.tsx` (line 5)
```tsx
// CURRENT (problematic)
import { motion } from "motion/react";  // Line 5

// Uses motion for animated overlays at lines 250, 277
<motion.img ... />
<motion.div ... />
```

**Analysis:**
- PasteInput is imported eagerly in `/src/app/page.tsx` (line 9)
- Motion library is ~580 KB raw (~90 KB gzipped in bundle)
- The homepage is the highest-traffic page
- Animations are secondary UX polish, not critical

**Recommended Fix:**
Extract animations to dynamic import or replace with CSS transitions:
```tsx
// Option A: Dynamic import
const AnimatedPasteInput = dynamic(() => import("./PasteInput"), { ssr: true });

// Option B: CSS-in-JS (Tailwind CSS transitions) replaces motion usage
// Remove motion, use Tailwind's group-hover/animate utilities
```

**Estimated Savings:** 80–120 KB gzipped (homepage FCP improvement ~15-20%)

### 3. Changelog data embedded in client bundle — ~8 KB reduction
**Severity:** LOW | **Risk:** VERY LOW | **Conflict Risk:** NO

**File:** `/src/app/changelog/data.ts` (137 lines)

**Analysis:**
- POSITIVE: Data is already extracted to separate file (not inline in component)
- ISSUE: ChangelogContent imports from data.ts client-side, bundling 137 lines of changelog text
- Alternative: Move to route handler or server component prop

**Current Structure** (Good but suboptimal):
```
changelog/page.tsx (Server Component)
  ├─ imports ENTRIES from data.ts
  └─ passes to ChangelogContent (Client Component)
      └─ client bundle grows by ~8 KB
```

**Recommended Fix:**
```tsx
// Option A: Server Component + client props (simpler)
export default function ChangelogPage() {
  return <ChangelogContent entries={ENTRIES} />;
  // data.ts stays server-only, never bundles to client
}

// Option B: API route + dynamic fetch
// Only fetch changelog data on demand (rarely visited page)
```

**Estimated Savings:** 5–8 KB gzipped (low impact, but technically possible)
