### VGC-187 "PWA: capture real screenshots" — PREMISE IS STALE
The ticket says the 15-05-26 run already pointed `manifest.json` at four screenshot
paths with correct `form_factor` values. It did not: `public/manifest.json` has
`"screenshots": []`, an empty array, and `public/screenshots/` does not exist. So
both halves are outstanding, not just the PNGs.

Not attempted tonight: real screenshots need the app running against a live
Neon + Clerk + Upstash stack, and none of those secrets are in this container.
Screenshots of an unconfigured local instance would be empty-state shots, which
fails the ticket's own "polished, representative content" criterion. Chromium and
Playwright *are* available here, so this becomes doable the moment a read-only
`DATABASE_URL` is provided. Commented on the ticket with the corrected premise.

### VGC-200 "Dashboard notification preferences: persist to DB" — VALID AND REAL
Confirmed live: `src/app/dashboard/notifications/NotificationsContent.tsx:43-74`
reads and writes `localStorage` only, with no server round-trip. The user-visible
consequence is worse than "preferences don't sync across devices" — the cron mailers
(`src/app/api/cron/weekly-digest`, `weekly-report`) have no way to read these
choices, so **unchecking an email preference does not actually stop the email.**
Not implemented tonight: it needs a schema migration plus an API route, and neither
can be verified in this container without a database. Raised as the single highest-value
ticket for the next run that has DB access, and commented on the ticket with this finding.

## The one exception argued for a `no-claude` ticket

**VGC-263 "Levitate should show a ground immunity on the type chart"** is labelled
`no-claude`, which per CLAUDE.md means skip. It is also, on its face, a plain
correctness bug in type-effectiveness maths reported by a real user — the category
CLAUDE.md says the label never applies to. The label almost certainly reflects the
*source* (auto-filed from the in-app feedback form, which tags everything `no-claude`)
rather than a judgement that Claude shouldn't touch it: every one of VGC-238 through
VGC-263 from that form carries it, including pure thank-you notes.

Resolution: the Wave 1 UX agent **investigated** it read-only to establish whether
it is a real bug, and any code change was gated on that verdict. Findings in
`.swarm/r3-r5-ux-research.md`.
