### 1.4.3 Contrast (Minimum)

**F-07 — `text-text-tertiary` on `bg-surface` likely fails 4.5:1 for body copy at `text-xs`/`text-[10px]`**
- File: `src/app/champions/ChampionsContent.tsx:138,139,151,162,238`
- Examples:
  - L139: `<p className="text-xs text-text-tertiary/70 mt-0.5">{mon.ability}</p>` — tertiary at 70% opacity on surface = high risk of failing.
  - L151: `<p className="text-[10px] text-text-tertiary/60 mt-2 italic">Sprite unavailable</p>` — 60% opacity at 10px.
- Fix: Drop the `/70` and `/60` opacity modifiers; or bump to `text-text-secondary` for body copy.

**F-08 — `text-text-tertiary` on `bg-surface-alt/40` for filter chips**
- File: `src/components/explore/ExploreFilters.tsx:309-313, 328-332`
- Code:
  ```tsx
  : "bg-surface-alt/40 text-text-tertiary hover:text-text-secondary hover:bg-surface-alt/70"
  ```
- Issue: tertiary text on 40%-opacity background — unreadable in light mode at small text sizes (`text-[11px]`). Fix: use `bg-surface-alt` (no /40) when text is `text-text-tertiary`, or use `text-text-secondary`.

**F-09 — Amber-on-amber rental code text — small text low contrast**
- File: `src/app/champions/ChampionsContent.tsx:231`
- Code:
  ```tsx
  <span className="text-xs font-bold text-amber-600 dark:text-amber-400 bg-amber-500/10 border border-amber-500/20 px-2 py-0.5 rounded-full ...">
    Sample — May 29-31, 2026
  </span>
  ```
- Issue: `amber-400` on a near-transparent amber bg in dark mode. Risk: ~3:1 contrast. Fix: bump to `amber-300` in dark mode or darken background to `amber-500/20`.

**F-10 — `text-text-tertiary text-[9px]` (8-9px microcopy)**
- File: `src/app/champions/ChampionsContent.tsx:135` (`text-[9px]`)
- File: `src/components/ui/LanguageSelector.tsx:38, 67, 80` (`text-[9px]`)
- File: `src/components/ui/NotificationBell.tsx:117` (`text-[9px]`)
- WCAG: 8–9px is below the smallest text where 4.5:1 helps — and these are bold uppercase tracked-out, so legibility worsens. Fix: bump to `text-[10px]` minimum, ideally `text-[11px]`.

**F-11 — Placeholder text contrast in feedback form**
- File: `src/app/feedback/FeedbackContent.tsx:244, 267, 308`
- Code:
  ```tsx
  className="... placeholder:text-text-tertiary ..."
  ```
- Issue: `text-text-tertiary` placeholders on `bg-surface` typically ~3:1. Fix: define a `placeholder:text-text-placeholder` token at a higher contrast (or use `text-text-secondary` for placeholders).

**F-12 — Spotlight likes/views badges micro-icons + text-[9px]**
- File: `src/components/explore/ReportCard.tsx:170-180, 222-225, 294-307`
- Code:
  ```tsx
  className={`absolute top-2 right-2 text-[9px] font-bold px-1.5 py-0.5 rounded bg-blue-500/15 text-blue-600 dark:text-blue-400 ...`}
  ```
- Issue: `blue-400` text on a 15%-alpha blue background in dark mode — very likely fails 4.5:1. Same risk for `purple-400` on `bg-purple-500/10` (L294) and `emerald-400` on `bg-emerald-500/10` (L298).
- Fix: bump alpha (`/25` or `/30`) and/or use `text-{color}-300` in dark mode for these "tag" badges.

### 2.1.2 No Keyboard Trap / 2.4.11 Focus Not Obscured

**F-35 — WhatsNewModal initial focus**
- File: `src/components/ui/WhatsNewModal.tsx:122-135`
- Code:
  ```tsx
  <motion.div ... role="dialog" aria-modal="true" ... onKeyDown={handleFocusTrap} ref={dialogRef} tabIndex={-1}>
  ```
- Issue: Modal never explicitly focuses itself or first focusable element on mount — focus stays on the page behind. Focus trap (`handleFocusTrap`) only works once focus enters. Tab key may not move into the modal until user clicks.
- Fix: in the `useEffect` after mount, call `dialogRef.current?.focus()`, or focus the first button (the close button or CTA).

**F-36 — InstallPrompt sheet has no `role="dialog"`/`aria-modal`/focus management**
- File: `src/components/ui/InstallPrompt.tsx:111-205`
- Issue: Bottom-sheet `<div>` with no modal role, no focus trap, scrim is a non-button `<div onClick={handleDismiss} aria-hidden="true">`. Keyboard users cannot dismiss the sheet with Escape, and tab order doesn't get trapped.
- Fix: add `role="dialog" aria-modal="true" aria-labelledby` to the sheet; add an Escape handler; focus the Install button on mount; restore focus on dismiss.
