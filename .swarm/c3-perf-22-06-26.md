4. **i18n already lazy.** `src/lib/i18n/index.ts` ships English statically and `import()`s `fr/it/es/ja/ko/zh` translation files on demand. **But see new finding #2 below — `move-names.ts` defeats this.**

## 4. Lazy-load candidates

### NEW #1 — `src/lib/data/move-names.ts` ships 6-language move strings on `/`
- **Importer chain:** `move-names.ts` → `src/lib/utils/translate-move.ts` → `PokemonCard.tsx`, `PokemonDetailSlide.tsx`, `TournamentMode.tsx`
- **Heavy module:** `MOVE_NAMES` constant — every common move has a 6-language record (Italian, Japanese etc.). Bundled into chunk `0am5u5.ao2_o4.js` = **97 KB raw / 29 KB gz** on `/`.
- **Why it's wasteful:** 95%+ of users are English; the i18n loader (`src/lib/i18n/index.ts`) is already lazy per language, but `translate-move` synchronously imports all language strings the moment any PokemonCard mounts.
- **Fix sketch:** Split `MOVE_NAMES` into one file per locale (`move-names.fr.ts`, `move-names.ja.ts`, …) and dynamic-import the matching one only when `useI18n().language !== "en"`. Approx **~25 KB gz saved** off `/`.

### NEW #2 — `zod` leaks into the home First Load via `url-codec`
- **Importer:** `src/lib/sharing/url-codec.ts` is imported by `src/app/page.tsx`, `useAutoDraft.ts`, `useShareFlow.ts`, `useShareUrl.ts`, `useCollaborativeSync.ts`, `diff-state.ts`, `version-diff.ts`. Module size: 6.2 MB on disk; minified zod runtime in the `/` page chunk is ~30-40 KB raw / ~10-12 KB gz.
- **Why:** zod is used for the URL-payload schema — that runs **only when** parsing/encoding a share URL, which is after the user clicks share or pastes a `/s/[id]` link. The schema doesn't need to be on the cold-load critical path.
- **Fix sketch:** Move the zod schemas into a separate file (`url-codec-schema.ts`) and `await import()` it inside `encode/decode` functions. Saves ~10 KB gz off `/` and most other pages.

### #3 — `motion/react` on `/feedback` and `/changelog` (low-leverage UX surfaces)
- **Importers:** `src/app/feedback/FeedbackContent.tsx` (14 motion uses), `src/app/changelog/ChangelogContent.tsx` (8 motion uses), `src/app/dashboard/profile/page.tsx` (7), `src/app/champions/[pokemon]/MegaLandingContent.tsx` (3).
- **Heavy module:** `motion/react` = 115 KB raw / 37 KB gz shared chunk.
- **Why it's wasteful:** These routes are content pages — no swipeable carousels, no spring physics. Most uses are `<motion.div initial opacity 0 animate opacity 1>` fades that Tailwind 4 can do with `animate-in fade-in` (`tailwindcss-animate` equivalents already in scope).
- **Fix sketch:** Replace motion fades with `transition-opacity duration-300 ease-out` + a tiny `data-loaded` hook. Keep motion for the home/Explore pages. Drops motion from 4 routes. Approx **35 KB gz off `/feedback`, `/changelog`, `/dashboard/profile`, `/champions/[pokemon]`** each.

### #4 — Dex-subset JSON ships duplicated on `/` and `/compare`
- **Files:** `0ri0npkdfd9o4.js` (on `/`) and `04jz-043dkbr4.js` (on `/compare`) — both 338,187 bytes, identical species data, different MD5s only because Turbopack assigns route-specific chunk IDs.
- **Why:** `src/lib/data/dex-subset.ts` is a synchronous import via `pokemon.ts`, which is in both routes' graphs. Turbopack emits a per-route copy instead of hoisting to the shared chunk.
- **Fix sketch:** Add `dex-subset` to `next.config.ts → experimental.optimizePackageImports`, or split the JSON into a `lib/data/dex-subset/index.ts` barrel and add `transpilePackages` mapping. If neither works in Next 16 Turbopack, ship the subset over a single `<script>` tag in the root layout (`next/script` with `strategy="lazyOnload"`). Saves ~48 KB gz off the second route the user navigates to.
- **Conflict risk:** none, dex-subset.ts not recently changed.

### #5 — `src/components/report/PokemonDetailSlide.tsx` still 963 LOC, not split
- **Heavy module:** itself, plus inline `translate-move` import (see #1).
- **Why:** All 5 tabs (Stats / Moves / Calcs / Matchups / Notes) sit in one client module. Eagerly bundled inside `TeamReport`. Re-renders on every tab change.
- **Fix sketch:** Same as last month — extract per-tab files + `dynamic()` the non-default tabs. Status: **not started**. Saves ~20-40 KB gz off the post-paste interactive bundle, big runtime win on mobile.

### #6 — `canvg` (156 KB raw) lazy-pulled by jspdf SVG plugin
- **Importer:** `jspdf` SVG-to-canvas plugin path inside `getJsPdf()`.
- **Status:** already lazy, but if PDF export rarely uses SVG, swap `jspdf` for the non-SVG entry (`jspdf/dist/jspdf.es.min.js`) and skip canvg entirely. Saves 24 KB gz on the export path.

## 7. Quick perf-win leverage ranking

(How many users × how many KB they save × how likely the change is safe to land.)

1. **Lazy-load `zod` out of url-codec** — biggest gz win per LOC, hits every cold-load on `/`. Conflict-risky.
2. **Move 6-language `MOVE_NAMES` behind the i18n loader** — ~25 KB gz off `/` for every English user (the majority). Independent of other work.
3. **Replace motion fades on `/feedback`, `/changelog`, `/dashboard/profile`, `/champions/[pokemon]` with Tailwind transitions** — 35 KB gz × 4 routes, zero risk.
4. **Dedup dex-subset JSON between `/` and `/compare`** — 48 KB gz on second-route nav, zero risk.
5. **Decompose `PokemonDetailSlide.tsx` for code-splitting (VGC-158)** — primarily a runtime/UX win on mobile, plus ~20-40 KB gz off the post-paste interactive bundle.
