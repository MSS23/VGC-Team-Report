## 4. Notifications Page (src/app/notifications/page.tsx)

**Status:** ⚠️ CRITICAL ISSUE

```tsx
export const metadata: Metadata = {
  title: "Notifications | VGC Team Report",
  description: "Your activity notifications.",
};
```

**Issues:**
1. ❌ **Missing `robots: noindex`** — This page shows logged-in user data (personal notifications). Should NOT be indexed.
2. ❌ **Missing canonical tag** — Though noindex will prevent indexing, canonical is good practice
3. ❌ **Weak description** — Generic text doesn't explain purpose
4. ❌ **Not in sitemap** — Correct, but noindex is still needed as a safety layer

**Required Fix:**
```tsx
export const metadata: Metadata = {
  title: "Notifications | VGC Team Report",
  description: "Your activity notifications.",
  robots: { index: false, follow: false },  // ADD THIS
  alternates: { canonical: "https://pokemonvgcteamreport.com/notifications" },  // ADD THIS (optional but good)
};
```

## TOP 3 QUICK WINS (Implementable Tonight)

### 1. Add `robots: noindex` to /notifications (CRITICAL)
**File:** `src/app/notifications/page.tsx`  
**Why:** Shows user-specific activity data. Private content should never be indexed.  
**Impact:** Prevents duplicate/thin content issues; improves crawl efficiency.

```tsx
export const metadata: Metadata = {
  title: "Notifications | VGC Team Report",
  description: "Your activity notifications.",
  robots: { index: false, follow: false },
};
```

### 2. Add Missing Canonical + Noindex to Dashboard Pages
**Files:** 
- `src/app/dashboard/page.tsx` (already has noindex, missing canonical)
- `src/app/dashboard/profile/page.tsx` (completely missing metadata)
- `src/app/dashboard/notifications/page.tsx` (missing noindex, has partial metadata)
- `src/app/dashboard/privacy/page.tsx` (no metadata)

**Why:** Dashboard is a protected route (requires Clerk authentication) and shows user data. Should never appear in search results.

**Example Fix (dashboard/profile/page.tsx):**
```tsx

export const metadata: Metadata = {
  robots: { index: false, follow: false },
};

  // ... existing component
}
```

### 3. Add Canonical Tags to /feedback, /compare (if they're canonical entry points)
**Files:**
- `src/app/feedback/page.tsx` (missing canonical)
- `src/app/compare/page.tsx` (has canonical ✅ — already correct)

**Why:** Canonical tags prevent duplicate-content issues and consolidate ranking signals, especially for tool/utility pages that might be accessible from multiple URLs.

**Impact:** Ensures correct version is ranked; improves crawlability.

```tsx

  title: "Feedback",
  description: "Request features, report bugs, or suggest improvements for VGC Team Report.",
  alternates: { canonical: "https://pokemonvgcteamreport.com/feedback" },
};
```
