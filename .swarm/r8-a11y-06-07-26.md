# R8 — Accessibility Audit (2026-07-06, WCAG 2.1 AA)

## Top 8 one-line quick wins (Wave 2 targets)

1. **`src/components/layout/PageNavbar.tsx:53-65`** — Desktop nav Links styled active by class only. Add `aria-current={activePage === link.key ? "page" : undefined}`. WCAG 4.1.2/1.3.1.

2. **`src/components/layout/PageNavbar.tsx:104-138`** — Mobile bottom-nav Links active pill class-only. Add `aria-current={isActive ? "page" : undefined}`. WCAG 4.1.2.

3. **`src/components/layout/PageNavbar.tsx:40`** — Desktop `<nav>` has no accessible name. Add `aria-label="Primary"`. WCAG 2.4.6.

4. **`src/components/layout/PageFooter.tsx:52`** — Footer `<nav>` also unnamed. Add `aria-label="Footer navigation"`. WCAG 2.4.6.

5. **`src/components/layout/PageFooter.tsx:34`** — Decorative chevron `<svg>` missing `aria-hidden`. Add `aria-hidden="true"`. WCAG 1.1.1.

6. **`src/components/ui/ShortcutHintOverlay.tsx:61`** — Modal missing dialog semantics. Add `role="dialog" aria-modal="true" aria-labelledby="shortcuts-title"` and `id="shortcuts-title"` on the `<h3>`. WCAG 4.1.2.

7. **`src/components/ui/WalkthroughOverlay.tsx:257-260`** — Missing `aria-modal="true"`. Add it plus `aria-labelledby` pointing to step title. WCAG 4.1.2.

8. **`src/app/champions/[pokemon]/MegaLandingContent.tsx:89-93`** — Breadcrumb `<nav>` missing `aria-label`; last crumb missing `aria-current="page"`. Add both. WCAG 1.3.1.

## Additional high-impact findings (Wave 2 candidates if time permits)

9. **`src/app/faq/page.tsx:150-153`** — Breadcrumb last-crumb `<span>` missing `aria-current="page"`. WCAG 1.3.1.

10. **`src/app/champions/ChampionsContent.tsx:139, 151`** — `text-text-tertiary/70` and `/60` opacity below 4.5:1 contrast. Drop opacity or use `text-text-secondary`. WCAG 1.4.3.

11. **`src/components/report/DefensiveCoverageChart.tsx:122`** and **`OffensiveCoverageChart.tsx:217-289`** — Tables missing `<caption>` and `scope="col"` on `<th>`. WCAG 1.3.1.

12. **`src/components/input/PasteInput.tsx:425`** — Textarea `focus:outline-none` without visible focus-visible ring. Add `focus-visible:ring-2 focus-visible:ring-accent/50`. WCAG 2.4.7.

13. **`src/components/report/TeamOverview.tsx:517,527,536,544,553,562`** — 6 inputs using `placeholder` as `aria-label`. Add proper `<label>` sr-only. WCAG 3.3.2.
