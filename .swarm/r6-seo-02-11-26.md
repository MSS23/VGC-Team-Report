## VGC-317 verdict (with evidence)

> *"Homepage and navbar server-render nothing, while the homepage emits FAQPage JSON-LD for content not present"*

### **TRUE as stated. Both halves confirmed, plus it is worse than the ticket says.**

**1. The homepage server-renders nothing.** `/` builds as `○ (Static)` — confirmed in tonight's route table — so the `useSearchParams()` bailout applies. The entire prerendered `<body>`, with `<script>` tags stripped, is **787 bytes / 39 characters of text**:

```
<body …><div hidden=""><!--$--><!--/$--></div>
<a href="#main-content" …>Skip to content</a>
<!--$!--><template data-dgst=""></template><!--/$-->          ← navbar boundary, empty
<div id="main-content">
  <!--$!--><template data-dgst=""></template>
  <p role="status" …>Loading team builder...</p>              ← the whole page
<!--/$--></div> … </body>
```

Measured: `h1 = 0`, internal content links = **0** (the only `href="/…"` in the file are `_next` chunks, favicons and `manifest.json`), body text = 39 chars.

- Chain: `src/app/page.tsx:9` → `src/components/home/HomePageServer.tsx:38` wraps everything in a single `<Suspense fallback={<p role="status">Loading team builder...</p>}>` → `HomePageClient` (`src/components/home/HomePageClient.tsx:9`) → `src/hooks/useHomePage.ts:64` `useSearchParams()`.
- **New since the last run, and it makes things worse rather than better:** `HomePageServer` now composes three *server* slots — `LandingSprites`, `LandingSteps`, `LandingFeedback` (`HomePageServer.tsx:44`, `:68`, `:90`) — and passes them as props to `HomePageClient` **inside** that same Suspense boundary (`HomePageServer.tsx:39`). Because the boundary emits its fallback, those slots never reach the DOM. Their strings ("Got a feature idea", "Paste your team", the Showdown sprite URLs) appear in `index.html` **only inside the React Flight payload**, not in markup. Someone did the work to create server-rendered landing content and it is 100% invisible to crawlers. One-line boundary change recovers all of it.

**2. The navbar server-renders nothing, sitewide.** `src/app/layout.tsx:134-136` is `<Suspense fallback={null}><PersistentNavbar /></Suspense>`; `src/components/layout/PersistentNavbar.tsx:36` calls `useSearchParams()`. Measured across all 98 prerendered pages: the marker `aria-label="Mobile navigation"` appears in **1** file — `tools/ev-to-sp.html`, which renders `PageNavbar` directly rather than through `PersistentNavbar`. The 6-link `NAV_LINKS` array in `PageNavbar.tsx:14-21` therefore contributes **zero** crawlable links on 97 of 98 pages. Every internal link in the build comes from `PageFooter`, and the homepage does not render `PageFooter`.

**3. The homepage emits FAQPage JSON-LD for content not on the page.** `HomePageServer.tsx:36` renders `<FAQPageJsonLd />`, which defaults to the 5 `DEFAULT_FAQ_ITEMS` in `src/components/seo/JsonLd.tsx:198-224`. Measured in `index.html`: 1 `FAQPage` block containing 5 `Question`/`acceptedAnswer` pairs, on a page whose rendered body is 39 characters. There is no FAQ anywhere in the homepage markup — there is no homepage markup. `HomePageServer.tsx:37` also emits a 5-step `HowTo` for steps that are likewise absent.

**Verdict detail:** nothing in VGC-317 is stale or already fixed. `index.html` is 38,959 bytes today — the same byte count the 26-10-26 run measured — i.e. zero movement.
