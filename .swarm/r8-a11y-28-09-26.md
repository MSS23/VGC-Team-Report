## Z3 — The same modal's listbox is not an announceable widget
- **WCAG** 4.1.2 Name, Role, Value — **A**

## C1 — Tailwind's `dark:` variant is not connected to the app's dark mode (123 usages)
- **WCAG** 1.4.3 — **AA**
- **Files** `src/app/globals.css:3-4` declares `@custom-variant creator` and

  attribute — set from `localStorage` in `src/app/layout.tsx:100` and toggled in
  `src/hooks/useDarkMode.ts:40-42`. `src/components/report/OffensiveCoverageChart.tsx:121`
  already documents the mismatch in a comment.

  1229,1232,1233,1238,1350,1352`, `ChampionsContent.tsx:244,321`,
  `PokemonDetailSlide.tsx:72,84,96,755,756,773,824,825,887-889`,
  `TeamOverview.tsx:243,271,272,491,514,866,886`, `CommonModesSlide.tsx:85,86,393,396,
  419,432`, `PokemonCard.tsx:515,516,533`, `CalcInput.tsx:202,203`,
  `TournamentMode.tsx:235,345`, `SlideNavControls.tsx:380`, `TeamReport.tsx:218`.
- **Computed, OS dark + app toggled light** (the `dark:` colour lands on `#FFFFFF`):
  `dark:text-amber-300` **1.44** · `dark:text-amber-400` **1.67** ·
  `dark:text-emerald-400` **1.92** · `dark:text-blue-400` **2.54** ·
  `dark:text-rose-400` **2.69** · `dark:text-red-400` **2.77**.

- **Diff** 1-3 lines, 1 file. **CONFLICT-RISK: yes** (`src/app/globals.css`, 1 open PR) —
