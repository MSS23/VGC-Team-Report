**Props interface:**

**Component structure:**
- Use `AnimatePresence` from `motion/react` to wrap the entire drawer output
- Use `useReducedMotion` from `motion/react` — when reduced motion is active, all animations collapse to opacity-only 100ms fade
- Detect mobile vs desktop with a `useMediaQuery` inline hook: `useState` + `useEffect` listening to `window.matchMedia("(min-width: 640px)")` — returns `isDesktop` boolean
- Compute `advancedFilterCount`: count of non-empty placement + non-empty eventType + (followingOnly === true ? 1 : 0)

**Mobile variant (< 640px):**
- Fixed backdrop: `fixed inset-0 bg-foreground/20 backdrop-blur-sm z-40` — click calls `onClose`
- Sheet container: `fixed bottom-0 left-0 right-0 z-50 bg-background rounded-t-2xl max-h-[85dvh] overflow-y-auto scrollbar-none`
- `motion.div` animation: `initial={{ y: "100%", opacity: 0 }}`, `animate={{ y: 0, opacity: 1 }}`, `exit={{ y: "100%", opacity: 0 }}`, enter transition `duration: 0.35, ease: [0.32, 0.72, 0, 1]`, exit transition `duration: 0.22, ease: "easeIn"`
- Drag handle: `<div className="w-8 h-1 bg-border rounded-full mx-auto mt-3 mb-4" />` (decorative only)
- Header row: "Advanced filters" heading (`text-sm font-bold text-text-primary`) + X close button (SVG, `aria-label="Close advanced filters"`, min `w-[44px] h-[44px]`)
- Attributes: `role="dialog"`, `aria-modal="true"`, `aria-label="Advanced filters"`, `id="advanced-filter-drawer"`
- Focus trap: on mount, call `querySelector` on the first focusable element inside the drawer and `.focus()` it

**Desktop variant (>= 640px):**
- No backdrop — click-outside handled via `useEffect` document click listener
- Panel: `absolute top-full left-0 right-0 mt-1 bg-background/95 backdrop-blur-lg border border-border rounded-xl shadow-lg z-40`
- `motion.div` animation: `initial={{ opacity: 0, scale: 0.96 }}`, `animate={{ opacity: 1, scale: 1 }}`, `exit={{ opacity: 0, scale: 0.96 }}`, enter transition `duration: 0.2, ease: [0.16, 1, 0.3, 1]`, exit transition `duration: 0.14, ease: "easeIn"`
- Attributes: `role="region"`, `aria-label="Advanced filters"`, `id="advanced-filter-drawer"`
- Escape key: `useEffect` with `keydown` listener calling `onClose` on Escape
