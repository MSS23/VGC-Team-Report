## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (`gap-1`, `p-1`) |
| sm | 8px | Compact element spacing (`gap-2`, `p-2`) |
| md | 16px | Default element spacing (`gap-4`, `p-4`) |
| lg | 24px | Section padding within drawer (`p-6`) |
| xl | 32px | Layout gaps between drawer sections |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Touch targets: minimum 44×44px for all interactive controls (filter chips, X button, clear button). Use `min-h-[44px] min-w-[44px]` where needed.
- "More filters" button: minimum `h-[36px]` to match existing filter bar button heights (consistent with archetype chips at `py-1 px-2`).
- Drawer drag handle: 32×4px pill, centered, 12px from top of sheet.
- Bottom sheet safe area: `pb-[env(safe-area-inset-bottom,0px)]` on mobile sheet footer.

## Interaction Contract

Source: `02-CONTEXT.md` decisions (locked).

### "More Filters" Button

- Sits at the end of the search category tab row, after the "Following" toggle (if present)
- Inactive state: `bg-surface-alt/50 text-text-secondary` — same as inactive category tab
- Active state (drawer open): `bg-surface-alt text-text-primary ring-2 ring-accent/30 ring-offset-1 ring-offset-background`
- Count badge: absolutely positioned top-right of the button, `bg-accent text-white text-[10px] font-bold`, `min-w-[18px] h-[18px]`, `rounded-full`, visible only when `advancedFilterCount > 0`
- Minimum touch target: `min-h-[44px]` on mobile, `h-auto py-2` on desktop
- `aria-expanded={drawerOpen}` — required
- `aria-controls="advanced-filter-drawer"` — required

### Drawer — Mobile (< `sm:` / < 640px)

- Full-width bottom sheet — slides up from bottom of viewport
- Animation: `animate-sheet-up` keyframe already defined in `globals.css` (translateY 100%→0, opacity 0→1), duration 350ms, `cubic-bezier(0.32, 0.72, 0, 1)`
- Exit animation: `animate-sheet-down` (translateY 0→100%, opacity 1→0), duration 220ms, `ease-in` — shorter than enter (63% ratio, per skill rule)
- Drawer height: `max-h-[85dvh]` with internal `overflow-y-auto scrollbar-none`
- Drag handle: 32×4px `bg-border rounded-full mx-auto mt-3 mb-4` — decorative, no swipe-to-close JS required (X button provides close)
- Backdrop: `fixed inset-0 bg-foreground/20 backdrop-blur-sm z-40` — tap to close
- Sheet z-index: `z-50` (above backdrop, above sticky filter bar at `z-30`)
- `role="dialog"`, `aria-modal="true"`, `aria-label="Advanced filters"`
- Focus trap: first interactive element inside drawer receives focus on open

### Drawer — Desktop (>= `sm:` / >= 640px)

- Dropdown panel below the primary filter bar, full width of the filter bar container
- Position: `absolute top-full left-0 right-0 mt-1` relative to a `relative` wrapper on the filter bar
- Background: `bg-background/95 backdrop-blur-lg border border-border rounded-xl shadow-lg`
- Animation: `fade-in-scale` keyframe (opacity 0→1, scale 0.96→1), duration 200ms, `cubic-bezier(0.16, 1, 0.3, 1)` — `motion/react` `AnimatePresence` + `motion.div`
- Exit: opacity 1→0, scale 1→0.96, duration 140ms, `ease-in`
- z-index: `z-40` (below mobile sheet, above page content)
- Click outside closes (document-level click listener with `useEffect`)
- Escape key closes (keydown listener)
- `role="region"`, `aria-label="Advanced filters"`, `id="advanced-filter-drawer"`

### Filters Inside Drawer

Layout: two-column grid on desktop (`grid grid-cols-2 gap-4`), single column on mobile (`flex flex-col gap-4`).

**Placement dropdown:**
- Reuses existing select styling: `px-3 py-2 pr-8 bg-surface border border-border rounded-lg text-xs font-semibold text-text-primary focus:ring-2 focus:ring-accent/40 focus:border-accent appearance-none cursor-pointer`
- Label: `text-[11px] font-bold uppercase tracking-wide text-text-tertiary mb-1` above the select
- Active indicator: When value is not empty, label turns `text-accent`

**Event type dropdown:**
- Same styling as Placement dropdown
- Active indicator: same pattern

**Following toggle (moved from primary bar):**
- Reuses existing toggle chip pattern: `inline-flex items-center gap-1.5 px-3.5 py-2 text-xs font-bold rounded-lg transition-all cursor-pointer active:scale-[0.97]`
- Active: `bg-accent text-white shadow-sm shadow-accent/20 ring-2 ring-accent/30 ring-offset-1 ring-offset-background`
- Inactive: `bg-surface-alt/50 text-text-secondary hover:text-text-primary hover:bg-surface-alt`
- Only rendered when user is authenticated (Clerk `user` check, same as current)
- `aria-pressed={followingOnly}` — required

### Instant Apply

All filter changes inside the drawer apply immediately on change — no "Apply" button. Matches existing behavior. Source: `02-CONTEXT.md`.

### Clear Filters

- Text button at the bottom of the drawer: "Clear advanced filters"
- Visible only when `advancedFilterCount > 0`
- Styling: `text-xs font-bold text-accent hover:text-accent/80 transition-colors cursor-pointer`
- Min touch target: `min-h-[44px]` with `flex items-center`
- Action: resets placement to `""`, eventType to `""`, followingOnly to `false`

### Drawer Close Methods

1. Click outside (desktop dropdown) or tap backdrop (mobile sheet)
2. Escape key (`keydown` listener, `useEffect` cleanup on unmount)
3. X button inside drawer header — `aria-label="Close advanced filters"`
4. Swipe down on mobile drag handle (optional progressive enhancement — not required for launch)

## Animation Specification

All animations use `motion/react` (`AnimatePresence` + `motion.div`). Existing `sheet-up`/`sheet-down` CSS keyframes in `globals.css` may be used as alternative for mobile sheet.

| Element | Enter | Exit | Duration | Easing |
|---------|-------|------|----------|--------|
| Mobile bottom sheet | `y: "100%"` → `y: 0`, `opacity: 0` → `1` | `y: 0` → `y: "100%"`, `opacity: 1` → `0` | Enter 350ms / Exit 220ms | Enter `cubic-bezier(0.32, 0.72, 0, 1)` / Exit `ease-in` |
| Desktop dropdown | `opacity: 0, scale: 0.96` → `opacity: 1, scale: 1` | reverse | Enter 200ms / Exit 140ms | Enter `cubic-bezier(0.16, 1, 0.3, 1)` / Exit `ease-in` |
| Mobile backdrop | `opacity: 0` → `opacity: 1` | reverse | Enter 200ms / Exit 200ms | `ease-out` |
| Count badge (appear) | `scale: 0.6, opacity: 0` → `scale: 1, opacity: 1` | `scale: 0.6, opacity: 0` | 150ms | `cubic-bezier(0.16, 1, 0.3, 1)` |

Constraint: animate `transform` and `opacity` only — never `width`, `height`, or layout properties. Source: `ui-ux-pro-max` skill.

Reduced motion override: All animations collapse to instant opacity-only fade (100ms) when `prefers-reduced-motion: reduce` is active.
