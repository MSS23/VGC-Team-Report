**File 1: src/app/dashboard/privacy/page.tsx (create new)**

Structure — follow the profile page pattern exactly:
- Export default `PrivacyDashboardPage` wrapping `<I18nProvider><PrivacyDashboardInner /></I18nProvider>`

Page layout:
- PageNavbar with activePage="dashboard"
- Back link at top of main: `<a href="/dashboard">` with left-arrow SVG icon + "Back to Dashboard" text, styled as `inline-flex items-center gap-1 text-xs text-text-tertiary hover:text-text-primary mb-6 transition-colors`
- Page title: "Data & Privacy" (h1, `text-2xl sm:text-3xl font-extrabold tracking-tight`)
- Page subtitle: "Manage your personal data stored by VGC Team Report." (`text-xs sm:text-sm text-text-secondary mt-0.5 mb-8`)
- Two sections separated by `<hr className="border-border my-8" />`

**Section 1 — Download My Data:**
- Section heading h2: "Download My Data" (`text-lg font-bold mb-2`)
- Description: "Export all your personal data — teams, notes, follows, reactions, and more — as a JSON file. You can request one export per 24 hours." (`text-sm text-text-secondary mb-4`)
- Button: "Download My Data" (accent style from interfaces block above)
- State: `const [downloading, setDownloading] = useState(false)` and `const [exportError, setExportError] = useState<string | null>(null)`
- On click handler:
  1. `setDownloading(true); setExportError(null);`
  2. `const res = await fetch("/api/user/export")`
  3. If `res.status === 429`: `setExportError("Export limit reached. You can download once every 24 hours."); setDownloading(false); return;`
  4. If `!res.ok`: `setExportError("Export failed. Please try again."); setDownloading(false); return;`
  5. `const blob = await res.blob()`
  6. `const url = URL.createObjectURL(blob); const a = document.createElement("a"); a.href = url; a.download = "vgc-data-export.json"; a.click(); URL.revokeObjectURL(url);`
  7. `setDownloading(false);`
- Button label: `downloading ? "Exporting..." : "Download My Data"`, disabled when `downloading`
- Error display below button: `{exportError && <p className="text-sm text-red-500 mt-2">{exportError}</p>}`

**Section 2 — Delete My Account:**
- Section heading h2: "Delete My Account" (`text-lg font-bold mb-2`)
- Warning text: "This permanently deletes all your teams, notes, follows, reactions, and your account. This action cannot be undone." (`text-sm text-text-secondary mb-4`)
- Button: "Delete My Account" (red/danger style — locked decision: must be red)
- State: `const [modalOpen, setModalOpen] = useState(false)`, `const [deleteInput, setDeleteInput] = useState("")`, `const [deleting, setDeleting] = useState(false)`, `const [deleteError, setDeleteError] = useState<string | null>(null)`
- On button click: `setModalOpen(true)`

**Confirmation modal** (rendered outside the sections, at the bottom of the signed-in block):
- Backdrop + card from interfaces block above
- Title: "Permanently delete your account?" (`text-lg font-bold mb-3`)
- Body: "This will erase all your teams, notes, follows, reactions, and your account login. Type DELETE to confirm." (`text-sm text-text-secondary`)
- Input: `<input type="text" value={deleteInput} onChange={(e) => setDeleteInput(e.target.value)} placeholder="Type DELETE to confirm" className="w-full mt-4 px-3 py-2 text-sm border border-border rounded-lg bg-background text-text-primary focus:outline-none focus:ring-2 focus:ring-red-500" />`
- Button row (`flex gap-3 mt-6 justify-end`):
  - Cancel button: `onClick={() => { setModalOpen(false); setDeleteInput(""); setDeleteError(null); }}` — style: `px-4 py-2 text-sm font-bold text-text-secondary border border-border rounded-xl hover:bg-surface-alt transition-all cursor-pointer`
  - Confirm button label: `deleting ? "Deleting..." : "Delete My Account"` — red/danger style, `disabled={deleteInput !== "DELETE" || deleting}` (exact string match — locked decision)
- Error below buttons: `{deleteError && <p className="text-sm text-red-500 mt-3">{deleteError}</p>}`
- On confirm handler:
  1. `setDeleting(true); setDeleteError(null);`
  2. `const res = await fetch("/api/user/delete", { method: "DELETE" })`
  3. If `!res.ok`: `setDeleteError("Deletion failed. Please try again or contact support."); setDeleting(false); return;`
  4. `await signOut({ redirectUrl: "/" });`
