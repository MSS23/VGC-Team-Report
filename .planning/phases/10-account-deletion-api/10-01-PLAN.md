The function must be an async DELETE handler (export async function DELETE()).

**Step-by-step implementation:**

1. Auth guard (per DATA-02):
   ```typescript
   const { userId } = await auth();
   if (!userId) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
   ```

2. Get share IDs owned by this user BEFORE deleting (needed for comments/reactions/creator_profiles). Include soft-deleted rows:
   ```typescript
   const userShares = await sql`
     SELECT id, data->>'creatorName' as creator_name
     FROM shares WHERE owner_id = ${userId}
   `;
   const shareIds = userShares.map(r => r.id as string);
   const creatorName = (userShares[0]?.creator_name as string) ?? null;
   ```

3. Execute cascade in this EXACT order (per locked decision in 10-CONTEXT.md):

   Step 1 — collection_items (via user's collection IDs):
   ```sql
   DELETE FROM collection_items
   WHERE collection_id IN (SELECT id FROM collections WHERE user_id = ${userId})
   ```

   Step 2 — collections:
   ```sql
   DELETE FROM collections WHERE user_id = ${userId}
   ```

   Step 3 — collaborators:
   ```sql
   DELETE FROM collaborators WHERE user_id = ${userId}
   ```

   Step 4 — edit_changelog:
   ```sql
   DELETE FROM edit_changelog WHERE editor_id = ${userId}
   ```

   Step 5 — share_versions:
   ```sql
   DELETE FROM share_versions WHERE editor_id = ${userId}
   ```

   Steps 6 & 7 — comments and reactions on user's shares (only if shareIds is non-empty, use conditional to avoid empty IN clause error):
   ```typescript
   if (shareIds.length > 0) {
     await sql`DELETE FROM comments WHERE share_id = ANY(${shareIds}::text[])`;
     await sql`DELETE FROM reactions WHERE share_id = ANY(${shareIds}::text[])`;
   }
   ```

   Step 8 — saved_reports:
   ```sql
   DELETE FROM saved_reports WHERE user_id = ${userId}
   ```

   Step 9 — follows:
   ```sql
   DELETE FROM follows WHERE user_id = ${userId}
   ```

   Step 10 — notifications:
   ```sql
   DELETE FROM notifications WHERE user_id = ${userId}
   ```

   Step 11 — feedback ANONYMIZE (locked decision — preserve bug reports, wipe PII only):
   ```sql
   UPDATE feedback SET submitter_id = NULL, submitter_name = NULL
   WHERE submitter_id = ${userId}
   ```

   Step 12 — shares (all, including soft-deleted):
   ```sql
   DELETE FROM shares WHERE owner_id = ${userId}
   ```

   Step 13 — creator_profiles (match by creator name from shares, only if creatorName exists):
   ```typescript
   if (creatorName) {
     await sql`DELETE FROM creator_profiles WHERE LOWER(name) = LOWER(${creatorName})`;
   }
   ```

4. Step 14 — Clerk deleteUser() AFTER all DB steps succeed (per DATA-03):
   ```typescript
   const client = await clerkClient();
   await client.users.deleteUser(userId);
   ```

5. Step 15 — Redis cache flush (FINAL step, per DATA-03):
   ```typescript
   // Flush share-level cache for each of the user's shares
   for (const id of shareIds) {
     await cacheInvalidatePrefix(`share:${id}`);
   }
   // Flush explore cache entirely (may contain deleted user's reports)
   await cacheInvalidatePrefix("explore:");
   ```

6. Return success:
   ```typescript
   return NextResponse.json({ deleted: true });
   ```

7. Wrap everything from step 2 onwards in try/catch. On error, return 500 with { error: "Deletion failed" } and log the error. Do NOT attempt partial rollback — if DB steps succeed but Clerk fails, data is already gone and that is acceptable per the locked decision.
